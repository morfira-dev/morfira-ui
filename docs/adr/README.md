# Architecture Decision Records

ADRs record durable, cross-package decisions for Morfira UI.

Statuses:

- **Proposed** — under review and not yet binding;
- **Accepted** — binding for new work;
- **Superseded** — replaced by a newer ADR;
- **Rejected** — considered but not adopted.

Accepted ADRs are not silently rewritten. Correct factual errors narrowly or add a new
ADR that supersedes the old decision.

Use `0000-template.md` for new records.
